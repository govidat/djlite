{% trans "How to read this report" %}

{% blocktrans %} Accuracy compares the version's forecast against the actuals for the same periods. At the aggregate level (the headline stats and the drill rows) the report uses value-based accuracy: quantities of different products cannot be added together, so a qty MAPE across several items is meaningless. Value (₹) is comparable, so Value MAPE is the headline accuracy measure. Per-item/line rows still show qty MAPE, which is meaningful for a single SKU. {% endblocktrans %}

{% trans "Measure" %} {% trans "Definition" %} {% trans "Meaning" %}
{% trans "MAPE %" %} |forecast − actual| ÷ actual × 100, per series {% trans "How far the forecast deviates from actuals, ignoring direction. Lower is better; 0% = perfect." %}
{% trans "Value MAPE %" %} Σ|forecast value − actual value| ÷ Σ actual value × 100 {% trans "Same idea but value-weighted, so it can be rolled up across many items. This is the headline score for aggregate rows." %}
{% trans "Bias %" %} (forecast − actual) ÷ actual × 100, per series {% trans "Direction of the error. Positive = over-forecast (plans too high); negative = under-forecast. Closer to 0 is better." %}
{% trans "Value Bias %" %} Σ(forecast value − actual value) ÷ Σ actual value × 100 {% trans "Value-weighted bias at aggregate level." %}
{% trans "Over-forecast %" %} {% trans "Share of series where forecast > actual" %} {% trans "How systematic the over-forecasting is across series." %}
{% trans "Avg MAPE %" %} {% trans "Simple mean of the per-row MAPE values" %} {% trans "Unweighted average across series; every row counts equally, unlike the value-weighted headline." %}

{% trans "What does the score mean?" %}

  • ≤ 25% — {% trans "good. Most forecasts land within a quarter of actuals." %}
  • 25 – 50% — {% trans "fair. Significant deviation; review the affected items." %}
  • > 50% — {% trans "poor. Forecasts are far from actuals; re-evaluate the series." %}

{% trans "Colours in the tables follow these same thresholds. Lower scores are always better." %}
